## Cross-baseline diagnosis

| Issue | Pages affected | Severity |
|---|---|---|
| Ghost face in ambient bg | about, services, platform, gallery, contact, onboard (all at 1200px) | P0 — unacceptable |
| Flat gold on body-tone backgrounds | index hero | P0 — gold reads as yellow |
| Gold inconsistency page-to-page | index vs about/results/contact use different weight + color | P1 |
| Cream serif vs gold display heading mismatch | about, services, results, gallery, contact use cream; index uses gold | P1 — pick one |
| 1200px dead space | platform, book, onboard, contact | P2 — layouts feel vertically stranded |
| Nav labels faint at 1200px | all pages | P2 |

## Fix plan

1. **Backgrounds**: dim every `.section-ambient-img` filter further (brightness ≤0.22, add dark gradient overlay). Ghost faces must be gone at 1200px.
2. **Gold**: 7-stop metallic gradient refined with brighter champagne highlight; apply `text-shadow` drop with a slight dark halo so it asserts against warm backgrounds.
3. **Headings**: standardize on the display serif in gold for hero headings, and cream serif for section headings, with an explicit `var(--heroGold)` vs `var(--sectionHead)` treatment. Document in site.css.
4. **Nav**: lift nav label opacity + letter-spacing + size.
5. **Dead space**: section padding reduced further on 1200px + soft ambient reinstated at the correct brightness.

## Systemic changes applied

- **`--goldGrad` upgraded** (css/site.css, app.html, portal.html): 5-stop with `#E8C547` peak → 7-stop with `#FFE8A0` champagne peak + `#F6CE56` secondary + `#3D2A08` deep bronze shadow. Parallel 7-stop crimson rose-metal for the portal crimson theme.
- **`.hero h1` metallic**: same 7-stop gradient + assertive `drop-shadow(0 3px 12px rgba(0,0,0,.85))` so the BIG MIKE ELY wordmark separates from the hero body photo at any size.
- **`.hero::before` text-band dimming**: new horizontal gradient (`top:40%;height:34%`) that puts a focused dark strip behind the hero wordmark so the metallic gold doesn't collide with Mike's warm skin tones. Desktop + mobile.
- **`.hero-content::before` vignette**: was desktop-only, now applied at every width with tighter radius + stronger opacity.
- **`.section-ambient-img` desktop filter**: was `brightness(.26)`, now `brightness(.12) saturate(.45) contrast(1.1) blur(4px)`. Every per-page filter override that was holding its own `!important` brightness was crushed to `.10–.09` with a 5px blur.
- **`.section-ambient::after` dark scrim**: was `transparent 40%`, now `rgba(3,3,2,.35) 20%` ramping to `.82` at edges so the viewport center is never a clear photo window.
- **Face-heavy ambient images swapped**: about (side-tricep → back-dbl-bicep), services (backstage-trio → gym-curls). Both had recognizable faces that survived the brightness crush.
- **`#about .section-ambient::after`** `!important` override rewritten with stronger opacity so the `about` radial vignette fully darkens regardless of the base rule.
- **`book.html` / `onboard.html` `.bg-ghost`**: `brightness(.3)` → `brightness(.14) blur(4px)` across all media-query overrides so the auth/onboarding surfaces read as pure atmosphere.
- **`portal.html` `.bg-photo`**: `brightness(.82)` → `brightness(.32) blur(4px)` so the olympia stage photo can never resolve into a figure during client login.
- **Monument year + crown year gradients**: updated to match the upgraded 7-stop metallic.
